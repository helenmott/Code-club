## Run Tests

Execute the test suite and display results:

1. Run test command: `npm test` or `pytest` depending on project
2. Report test results and coverage
3. Flag any failing tests or low coverage areas

## Usage

`/test-locally` - Run full test suite
`/test-locally unit` - Run unit tests only
`/test-locally integration` - Run integration tests
